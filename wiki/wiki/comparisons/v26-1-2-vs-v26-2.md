# v26_1_2 vs v26_2 差异

## 维度对比

| 维度 | v26_1_2（stable） | v26_2（beta 0.7-beta） |
|---|---|---|
| MC 版本 | 26.1.2 | 26.2 |
| NeoForge | 26.1.2.76 | 26.2.0.7-beta |
| NeoGradle | 7.1.38 | 7.1.38 |
| Java | 25 `--enable-preview` | 25 `--enable-preview` |
| pack_format | 80 | 81 |
| 平台入口 | `Platform26` | `Platform26V2`（独立 `IPlatform`，`mcVersion()` 返回 `"26.2"`） |
| 包名 | `com.reclizer.csgobox.v26_1_2.*` | `com.reclizer.csgobox.v26_2.*` |

## 破坏性 API 变更

| 变更 | v26_1_2 | v26_2 |
|---|---|---|
| HUD 隐藏 | `Options.hideGui` 存在 | 字段移除 → `HudVisibility` 工具类（`Minecraft.gui.hud.toggle()/isHidden()`） |
| Screen 设置 | `Minecraft.setScreen(Screen)` | `Minecraft.setScreenAndShow(Screen)` |
| PIP 渲染器 | `PictureInPictureRenderer` 接收 `MultiBufferSource` | 不再接收（`renderToTexture(state, poseStack, SubmitNodeCollector)`） |
| `CriterionTrigger` | 抽象类 | interface |
| `GameRenderer` | `getLighting()` | `lighting()` |
| `@EventBusSubscriber` | 有 `bus` 参数 | 已移除 `bus` 参数（默认 MOD 总线） |

## 功能等价性

- 3D 旋转：v26_2 保留 `scale(1,-1,-1)` + `Axis.{XP,YP,ZP}.rotationDegrees`，`Icon3DRenderer` 完全重写（106→99 LOC）
- 其余功能：批量开箱、成就、动态注册、教程等行为一致
- 当前状态：26.2 仍为 beta（最新 26.2.0.40-beta），保持 26.2.0.7-beta 不升级
