# 1.21.1 vs 26.1.2 GUI 渲染管线对比

## 维度对比表

| 维度 | 1.21.1（旧 API） | 26.1.2（decoupled API） |
|---|---|---|
| Screen 入口 | `render(GuiGraphics, ...)` | `extractRenderState(GuiGraphicsExtractor, ...)` |
| 矩阵 | `PoseStack`（3D） | `Matrix3x2fStack`（2D，JOML） |
| 渲染管线 | 静态 `RenderSystem` 调用 | `RenderPipelines.GUI_TEXTURED` 等 |
| 3D 物品预览 | `BakedModel` 渲染管线 | `PictureInPictureRenderer` + `Icon3DRenderer`（PIP 3D） |
| 2D 物品网格 | 直接 blit | `guiGraphics.item(...)`（deferred item pipeline） |
| Blit 签名 | 9-arg overload | `blit(RenderPipeline, Identifier, ...)` |
| 分层 | 单 stratum | `guiGraphics.nextStratum()`（引擎控制排序） |
| 按钮色 | 硬编码 `0xFF00AA00` / `0xFFFF0000` | `ButtonPalette.OPEN` / `DANGER` token |
| 文本限宽 | 裸 `Font.width` | `RenderFontTool.drawStringClamped` + 省略号 |
| 工具提示 | 裸 `renderTooltip` | `RenderFontTool.drawString` 返回宽度 |
| HUD 隐藏 | `Options.hideGui` | 26.2 移除 → `HudVisibility` 包装 |

## 网络与事件差异

| 维度 | 1.21.1 | 26.1.2 |
|---|---|---|
| 网络包发送 | `PacketDistributor.sendToPlayer` | `IPayloadContext.reply()`（handler 内直接回复） |
| 客户端发送 | `PacketDistributor.sendToServer` | `Connection.send(new ServerboundCustomPayloadPacket(...))` |
| 鼠标事件 | `event.getButton()` | `event.buttonInfo().button()` |
| Attachment 序列化 | `Builder.serialize(Codec)` | `IAttachmentSerializer<T>` 接口 |
| Registry 查询 | `BuiltInRegistries.ITEM.get(key)` | `BuiltInRegistries.ITEM.get(key).get().value()`（Optional） |
| `spawnAtLocation` | `mob.spawnAtLocation(mob.level(), stack)` | `mob.spawnAtLocation((ServerLevel) mob.level(), stack)` |

## 功能等价性

| 功能 | 1.21.1 | 26.1.2 |
|---|---|---|
| 3D 物品旋转 | 完整 3D（PoseStack X+Y 轴） | 降级为 2D Y 轴近似（Matrix3x2fStack 无 z） |
| 物品拖拽缩放 | PoseStack 3D scale | Matrix3x2f 2D scale + translate |
| 开箱动画 | 120ms tick 节流 | 同上 |
| renderItem seed | 无 | 新增第 5 参数 seed |

## 结论

- 26.x decoupled API 更现代、更安全（分层渲染、管线化），但 3D 旋转能力降级
- `ButtonPalette` / `RenderFontTool` / `Icon3DRenderer` 是 26.x 独有工具类，弥补 API 差异
- 1.21.1~1.21.5 无 `ItemModelResolver` API，per-item 居中仅 26.x + 1.21.8/10/11 支持
