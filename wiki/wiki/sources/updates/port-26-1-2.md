# docs/port-26.1.2.md（26.1.2 移植说明）

## Summary
MC 1.21.1 → 26.1.2 移植的完整变更记录。11 项 API 破坏性变更 + 6 项修复。

## Key takeaways
- **11 项 API 变更**：Screen 构造器（`minecraft` final）、`TagParser.parseTag`→`parseCompoundFully`、`appendHoverText` 新签名（TooltipDisplay + Consumer）、`AttachmentType` 序列化 IAttachmentSerializer、`PoseStack`→`Matrix3x2fStack`、`renderItem` seed 参数、网络包 `IPayloadContext.reply()`、`MouseButtonEvent` 事件 API、`Registry.get` 返回 Optional、`Entity.spawnAtLocation` 需 ServerLevel 强转、`Container.items` 私有化
- **6 项修复**：`PacketCs2Progress.handleServer` 死代码、`ItemCsBox.appendHoverText` 尊重 `TooltipDisplay.hideTooltip()`、网络包 `IPayloadContext.reply()` 统一、`BoxJsonLoader` 教程版本号更新、`ModSounds` 风格统一、`PacketBoxOpenResult` 线程安全注释
- 3D 物品旋转降级为 2D 旋转（`Matrix3x2fStack` 无 z 轴）
- `@EventBusSubscriber` 注解仍然存在（经反编译验证）
