# Spartan Weaponry + Spartan Shields 箱子包

- **目标模组**：Spartan Weaponry 3.2.1-all + Spartan Shields 3.1.1（1.20.1 Forge 实测）
- **平台限制**：双模组另有 1.18.2 构建；shouldersurfing 为可选前置（不装不影响）
- **物品池**：netherite 大剑/戟/塔盾 grade5，diamond 长柄/重弩 grade3-4，iron 系与盾牌铺中段；
  Weaponry 的合金材质（钢/银/青铜等）依赖对应矿物模组注册，**只收 vanilla 材质**避免缺 id
- **id 来源**：两 jar `models/item/` 清单 × 材质前缀实测
- **文件**：`spartan_crate.json` + `spartan_terminal.json`
