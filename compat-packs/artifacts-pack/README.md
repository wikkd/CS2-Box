# Artifacts（神秘饰品）箱子包

- **目标模组**：Artifacts Forge 9.5.19（1.20.1；前置 curios + expandability + cloth_config + architectury；
  expandability 在 Modrinth 无 1.20.1 构建，从 CurseForge 取 v9.0.4）
- **平台限制**：Artifacts 是本轮唯一有 26.x 构建的候选（26.1/26.1.2 线），后续 26.x 收编可直接复用选品
- **物品池**：全模组 43 件饰品按强度分档（强力磁铁/永恒牛排 grade5；近战系 grade4；
  功能系 grade3；生存小件 grade1-2），含宝箱怪刷怪蛋
- **id 来源**：9.5.19 发布 jar `models/item/` × `zh_cn` lang 交叉实测（_blocking/_gui/_idle
  渲染变体模型不进池）
- **文件**：`artifacts_crate.json` + `artifacts_terminal.json`
