# Forge 1.20.1 平台模块移植计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `forge_1_20_1` 平台模块，将 CS2 Box 1.0.7 线全部功能移植到 MinecraftForge 47.x（MC 1.20.1），作为项目第 6 个平台模块。

**Architecture:** 以 `forge_26_1_2` 为基准，用 ForgeGradle 6.0 构建，复用 `common/` 全部纯 Java 代码。Networking（SimpleChannel）、Capability（LazyOptional）、渲染（GuiGraphics 直调）是三大重写区域。DataComponent → NBT 回退。PIP 系统不存在于 1.20.1，需替代方案。

**Tech Stack:** MinecraftForge 47.4.22, ForgeGradle 6.0, Java 17, Gradle 9.2+, JEI 15.x

## Global Constraints

- `common/` 不得 import `net.minecraft.*` / `net.minecraftforge.*`（CONSTRAINT-001）
- 平台模块通过 `srcDir project(':common').file('src/main/java')` 共享 common 源码
- 版本号跟随主线 `mod_version`（当前 1.0.6），不延续老仓库 2.0.1
- `forge_1_20_1` 为实验模块，不在 CI 矩阵，不参与 3 平台镜像纪律/AnimRenderOps 漂移门禁
- AnimRenderOps 13 个 op 的签名必须与其他平台对齐（参数类型可不同，语义必须一致）
- PIP 渲染在 1.20.1 不存在，用 `renderItem` 直调替代（简化方案，无 3D 预览窗口）

**Forge 47.x Capability 模式:**

```java
// 获取 capability 引用
public static final Capability<CsboxPlayerData> CAP =
    CapabilityManager.get(new CapabilityToken<>(){});

// AttachCapabilitiesEvent 注册
@SubscribeEvent
public static void attachCaps(AttachCapabilitiesEvent<Entity> event) {
    if (event.getObject() instanceof Player) {
        var provider = new ICapabilitySerializable<CompoundTag>() {
            private final CsboxPlayerData data = new CsboxPlayerData();
            private final LazyOptional<CsboxPlayerData> opt = LazyOptional.of(() -> data);

            @Override
            public <T> LazyOptional<T> getCapability(Capability<T> cap, Direction side) {
                return cap == CAP ? opt.cast() : LazyOptional.empty();
            }

            @Override
            public CompoundTag serializeNBT() { return data.toNbt(); }

            @Override
            public void deserializeNBT(CompoundTag nbt) { data.fromNbt(nbt); }
        };
        event.addCapability(new ResourceLocation("csgobox", "player_data"), provider);
        event.addListener(provider::invalidate);
    }
}
```

**这是最关键的适配文件。** AnimRenderOps 是各平台的唯一渲染适配点。

**1.20.1 渲染 API 映射:**

| AnimRenderOps op | 26.x (GuiGraphicsExtractor) | 1.20.1 (GuiGraphics) |
|---|---|---|
| `blitTextured(gg, tex, x, y, w, h)` | `gg.blit(...)` (RenderPipeline) | `gg.blit(...)` — **相同** |
| `fill(gg, x1, y1, x2, y2, color)` | `gg.fill(...)` | `gg.fill(...)` — **相同** |
| `fillGradient(gg, ...)` | `gg.fillGradient(...)` | `gg.fillGradient(...)` — **相同** |
| `scissor(gg, x1, y1, x2, y2)` | `gg.enableScissor(...)` | `gg.enableScissor(...)` — **相同** |
| `scissorDisable(gg)` | `gg.disableScissor()` | `gg.disableScissor()` — **相同** |
| `setBlendNormal(gg)` | RenderPipeline 管理 | `RenderSystem.defaultBlendFunc()` |
| `flush(gg)` | 无操作 | `RenderSystem.setShaderColor(1,1,1,1)` |
| `renderBlurredBackground(gg)` | `gg.renderBlurredBackground(...)` | `gg.renderBlurredBackground(...)` — **相同** |
| `renderItem2D(entity, gg, stack, x, y, size)` | `ItemModelResolver` + tracking | `gg.renderItem(stack, x, y)` + `gg.renderItemDecorations(...)` |
| `renderItem3D(gg, stack, player, x, y, ...)` | PIP 3D 渲染 | **降级为 2D** `gg.renderItem(...)` |
| `supports3D()` | `true` | `false` |

1. `GuiGraphicsExtractor` → `GuiGraphics`

3. `RenderPipelines` 不存在 → 用 `RenderSystem` 直接管理
4. `ItemModelResolver` 不存在 → 用 `Minecraft.getInstance().getItemRenderer()`
