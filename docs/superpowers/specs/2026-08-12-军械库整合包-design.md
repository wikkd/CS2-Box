# 设计：军械库整合包（CS:GO 精神续作 · 开箱玩法）

日期：2026-08-12
状态：草稿待审
模块：整合包（客户端）/ csgobox 配置 / KubeJS / 资源包 / FTB Quests / Bountiful

## 背景与需求

用户要做「开箱玩法」整合包，csgobox 模组（1.0.6-beta）作为 beta 版集成测试。用户负责下载文件，我负责全部设计。

客户端现状（已确认）：
- 目录：`client/versions/1.21.1-NeoForge/`，MC 1.21.1 + NeoForge + HMCL
- mods 已有约 68 个 jar：TACZ 1.1.8-hotfix-r6、KubeJS 2101.7.2-build.368、JEI、Sodium/Iris、csgobox-1.21.1-1.0.6-beta.jar（已集成）
- 已有实用模组：sophicatedbackpacks（背包）、waystones（传送点）、gravestone（墓碑）、touhoulittlemaid（女仆）等

已确认的约束（与用户逐项确认）：
- 主题 = 现代军械抽奖（CS:GO 精神续作），TACZ 枪械为核心
- 核心循环 = 打怪掉箱 + 经济链 + 阶段终局（C+D 结合）
- 钥匙经济 = 铁钥匙打怪掉落；金/钻钥匙村民/终端购买；下界合金钥匙保留锻造链（钻钥匙 + 升级模板）
- 阶段划分 = 主世界 → 下界 → 末地三阶段
- 箱子组织 = 每维度 2 个平行系列（共 6 主线箱 + BOSS 专属箱），每箱 8-12 件物品池
- 模组范围 = 军事为主 + 保留实用模组；**掉落物纯军事**；纯客户端模组保留
- 货币 = csgobox 内置「武库点数」（`csgobox:armory_point`）
- 皮肤枪 = 命名 + 预装配件 + 附魔光效（如 `AK-47 | 霓虹革命` 自带消音器 + 2 倍镜）
- 方案 = C 完整整合包体验（配置 + KubeJS + 资源包 + 任务书）
- 玩法模块 = 模块 2（图鉴收集线）+ 模块 3（终局挑战线）

## 核心概念

- **一句话**：在 Minecraft 里打怪开箱抽军械——每个维度有自己的武器箱系列、钥匙与 BOSS，最终目标是集齐图鉴、用传说钥匙打开军械库宝箱。
- **掉落物纯度**：所有箱子/掉落只产出军事物品（TACZ 枪械、配件、弹药、军械材料）+ 武库点数/钥匙；背包、传送点、女仆等实用模组保留功能但不进掉落池。
- **beta 定位**：csgobox 1.0.6-beta 集成，玩法先按本文档落地，数值在 beta 实测后调整。

## 核心循环（C+D：打怪掉箱 + 经济链 + 阶段终局）

```
打怪 ──→ 掉箱子 + 铁钥匙（主世界概率高）
  │
  ▼
开箱 ──→ 5 档稀有度物品（皮肤枪 / 配件 / 弹药 / 材料）
  │
  ├─→ 皮肤枪 ──→ 图鉴首次登记（模块2）／重复 3 换 1 自选
  ├─→ 垃圾/材料 ──→ 回收机 ──→ 武库点数
  ├─→ 材料卖军火商 ──→ 武库点数
  ▼
武库点数 ──→ 军火商购买金/钻钥匙、终端机
  │
  ▼
进入下一维度 ──→ 挑战 BOSS ──→ BOSS 箱 / 钥匙碎片
  │
  ▼
末地终局 ──→ 传说钥匙（碎片锻造）──→ 军械库宝箱（毕业装）
```

## 三阶段结构（A：主世界 → 下界 → 末地）

| 阶段 | 箱子系列 | 钥匙 | 经济门槛 | 挑战/BOSS |
|---|---|---|---|---|
| 阶段 1 主世界 | 步枪箱、手枪配件箱 | 铁钥匙（打怪掉率高） | 无 | 地牢精英怪（When Dungeons Arise 地牢） |
| 阶段 2 下界 | 狙击箱、特种武器箱 | 金钥匙（军火商 Lv4，24 点） | 武库点数经济成型 | 灾变 Ignis（L_Ender's Cataclysm） |
| 阶段 3 末地 | 传说武器箱、军械库宝箱 | 钻石钥匙（45 点 + 1 钻石）→ 锻造下界合金钥匙 | 图鉴 + 挑战线完成 | Ancient Remnant / Harbinger（灾变） |

阶段推进规则：
- 主世界箱子钥匙可自然掉落；下界/末地钥匙必须靠点数购买或 BOSS/地牢获取。
- 每阶段解锁对应军火商交易等级（军火商职业等级 1-5 天然对应阶段推进）。
- 阶段 3 的「军械库宝箱」需要下界合金钥匙（钻石钥匙 + 锻造模板，仅锻造台），是毕业箱。

## 箱子系列与物品池（6 主线 + 1 BOSS 专属 + 终端机）

每箱 8-12 件物品，按 5 档稀有度（grade1-5）分布：低档 3-4 件、中档 3 件、高档 2-3 件、隐秘级 1-2 件。物品 ID 以 TACZ 1.1.8 实际注册名为准，实施时逐个核对。

### 1. 步枪箱（主世界 · 铁钥匙）
- grade1：白板 AK-47 / M4A1 / HK416、弹药盒
- grade2：基础涂装步枪（如 M4A1 \| 石墨）、扩容弹匣
- grade3：中档皮肤枪、消音器、红点瞄具
- grade4：高档皮肤枪（如 AK-47 \| 霓虹革命：消音器 + 2 倍镜 + 附魔光效）
- grade5：隐秘级皮肤枪（如 M4A1 \| 龙纹）、小型军械套装
- 池大小：约 10 件

### 2. 手枪配件箱（主世界 · 铁钥匙）
- 手枪皮肤枪（Glock / M1911 / DEagle 系）、瞄具/消音/扩容配件、弹药
- 池大小：约 9 件，偏配件向，是前期改装核心来源

### 3. 狙击箱（下界 · 金钥匙）
- 狙击皮肤枪（AWP / M82 系）、8 倍镜/12 倍镜、穿甲弹药、狙击配件
- 池大小：约 10 件

### 4. 特种武器箱（下界 · 金钥匙）
- 霰弹（M870 / SPAS-12）、冲锋枪（MP7 / Vector / UMP45）、机枪（M249 / RPD）皮肤枪
- 池大小：约 11 件，近战爆发向

### 5. 传说武器箱（末地 · 钻石钥匙）
- 顶配皮肤枪（全系列隐秘级变体）、传说级配件（复合瞄具等）
- 池大小：约 10 件，末地中期核心产出

### 6. 军械库宝箱（末地 · 下界合金钥匙，锻造获得）
- 全系列混合大池（6 系列精选），5 档权重向高档倾斜，隐秘级概率最高
- 池大小：约 12 件，毕业箱

### 7. BOSS 专属箱（各阶段 BOSS 掉落，需对应阶段钥匙或免钥匙）
- 地牢精英怪 / Ignis / Ancient Remnant / Harbinger 各掉专属箱（免钥匙，BOSS 已是成本）
- 内含该 BOSS 限定皮肤枪（不进普通箱池）
- 池大小：每 BOSS 8 件

### 8. 终端机（保留现有设计，军火商 Lv4 购买，18 点）
- 免钥匙高价值分发器：下界合金装备 / 钻石装备（随机权重向高档倾斜），维持默认配置

## 5 档稀有度与皮肤枪设计

| 档位 | 名称 | csgobox grade | 掉落率权重（默认 random） | 颜色 |
|---|---|---|---|---|
| 1 | 消费级 Consumer | grade1 | 625 | 白 |
| 2 | 工业级 Industrial | grade2 | 125 | 浅蓝 |
| 3 | 军规级 Mil-Spec | grade3 | 25 | 蓝 |
| 4 | 受限级 Restricted | grade4 | 5 | 紫 |
| 5 | 隐秘级 Classified | grade5 | 2 | 红 |

皮肤枪规格（B：命名 + 预装配件 + 附魔光效）：
- 命名：`武器 | 涂装名`，如 `AK-47 | 霓虹革命`、`M4A1 | 龙纹`、`DEagle | 金蚀`
- 预装配件：枪口/瞄具/弹匣通过 `components` 预装（TACZ 配件物品直接附在枪上）
- 附魔光效：用 csgobox `components` 自定义附魔 + 光泽（1.21.1 用 enchantment_glint 组件），皮肤枪比白板更醒目
- 名称颜色：csgobox `name` 支持 `#RRGGBB ` 颜色前缀，按稀有度档位统一着色
- 弹药配套：每把皮肤枪附赠对应弹药一盒，开箱即用

## 武库点数经济

来源：
- 回收机（`ArmoryRecyclerBlockEntity.yieldForGrade` 硬编码）：grade1=3、grade2=5、grade3=7、grade4=8、grade5=8；40 tick/件，无燃料，支持漏斗
- 军火商收购（`villager_trade/arms_dealer`）：铁锭 1→2 点、绿宝石 1→2 点、金锭 1→4 点、钻石 1→12 点
- 任务奖励（FTB Quests）

锚定（以军火商交易为基准）：
- 铁钥匙 = 9 点（Lv3）
- 金钥匙 = 24 点（Lv4）
- 钻石钥匙 = 45 点 + 1 钻石（Lv5）
- 普通箱 = 8 点（Lv2）、终端机 = 18 点（Lv4）

防刷钳制：
- grade4/5 单件回收钳制在 8 点 < 9 点铁钥匙成本——**任何单件开箱所得永远兑不出一把钥匙**，防止回收刷钥匙循环
- 皮肤枪（TACZ 物品）回收走图鉴 3 换 1 路线而非点数化，高价值物品不进入点数经济
- beta 阶段若出现刷点路径（如特定配件可叠合成千上万），用 KubeJS 屏蔽对应物品回收

## 模块 2：图鉴收集线

目标：收集驱动，让重复开箱有沉淀价值。

- **首次获得登记**（KubeJS）：玩家首次获得某皮肤枪时写入全局进度（记名 + 系列），重复获得不再计数
- **收集任务**（FTB Quests）：按 6 系列设收集任务，集齐 N 件该系列皮肤枪 → 奖励（武库点数 / 兑换券 / 配件）
- **重复 3 换 1 自选**（KubeJS + FTB Quests）：
  1. 任意 3 把皮肤枪（同系列）在工作台合成 → 1 张「军械库兑换券」
  2. 兑换券在 FTB Quests 的奖励选择中兑换该系列任意一把已解锁（图鉴已登记）的皮肤枪
  3. 图鉴未解锁的枪不可兑换，倒逼收集
- 图鉴进度同步到 JEI/任务书，未收集项显示"？"（防剧透，可选）

## 模块 3：终局挑战线

目标：给经济循环一个终点目标。

- **钥匙碎片**：灾变 BOSS（Ignis / Ancient Remnant / Harbinger）掉落「传说钥匙碎片」（分片，如 3 片合成 1 把传说钥匙）
- **传说钥匙**：碎片合成，仅能开「军械库宝箱」；宝箱在末地 / 地牢结构生成点保底放置
- **保底箱**（When Dungeons Arise）：地牢每座必出 1 个对应阶段保底箱（铁/金钥匙箱），保证结构探索有收益
- **毕业判定**：集齐全部 6 系列图鉴 + 开出军械库宝箱隐秘级皮肤枪 = 毕业

## 已知问题：配方 bug 修复计划

**问题**：csgobox 1.0.6 的 4 个钥匙配方在 1.21.1 全部解析失败（服务端报 "Not a JSON object"）：
- `csgo_key0.json` / `csgo_key1.json` / `csgo_key2.json` / `csgo_key3_smithing.json`
- 已确认根因：key 写作 `"I": ["minecraft:iron_ingot"]`（数组内裸字符串），1.21.1 Ingredient 不接受该写法；需改为单字符串 `"I": "minecraft:iron_ingot"` 或对象 `{"item": "..."}`
- 对照：`armory_point_exchange.json` / `armory_recycler.json` 用单字符串写法，正常解析——佐证根因

**修复方案**（在 csgobox 仓库实施，遵循三平台镜像纪律）：
- 6 个配方文件统一改为单字符串/对象写法（`common/src/main/resources/data/csgobox/recipe/`）
- 修复后 `armory_point_exchange.json`（9 点 → 铁钥匙）成为玩家可用的点数消费路径——注意此合成与军火商 9 点交易并存，属预期双通道，保留
- 同步到各平台资源目录（共享资源在 common，单处修改全平台生效，无镜像风险）
