## 0. 一句话定位

> **在 Minecraft 里打怪 → 掉箱 → 开箱抽军械（TACZ）→ 攒武库点数 → 解锁下一维度 → 挑战 BOSS → 集齐图鉴、开启军械库宝箱毕业。**

核心铭牌：csbox 是**唯一经济/掉落出口**；PvE 是**唯一箱子来源**；FTB Quests 是**唯一主线叙事**。箱子只会掉出来、开出来、买出来——不存在第三条产出路径（保证整合包「以 csbox 为核心」可感知）。

## 1. 设计原则

| 原则 | 含义 |
|---|---|
| P1 掉落纯军械 | 所有箱子/掉落池只产 TACZ 军械、配件、弹药、军械材料、钥匙与武库点数；Create/背包/女仆等**功能保留，不进掉落池**（承接旧设计） |
| P2 三阶段难度门 | 主世界 → 下界 → 末地：钥匙等级与经济门槛逐级抬高，BOSS 是阶段硬闸门（旧设计沿用） |
| P3 服务端权威 | 开箱 RNG、终端谈判、回收点数均为 csgobox 服务端权威；脚本只做「事件后通知/登记」与「事件前允许/拒绝」 |
| P4 防刷钳制 | 任何单件开箱所得点数 < 铁钥匙成本（9 点），杜绝「回收刷钥匙」闭环；高价值皮肤枪不进点数经济 |
| P5 主线可完成 | FTB Quests 全程有依赖链与自选奖励；毕业判定明确（见 §7） |
| P6 数值可调 | 全部箱子池/价格/任务奖励集中在 `config/csbox/`、`_prices.json`、FTB Quests 文件，改 JSON 即调难度 |

## 3. 核心循环（PvE 闭环）

```
PvE 打怪/地牢/BOSS ──→ 掉「箱子 + 钥匙」（csbox entity 掉落实体配置）
        │
        ▼
开箱（5 档稀有度 RNG，服务端权威）──→ 皮肤枪 / 配件 / 弹药 / 材料
        │
        ├─→ 皮肤枪 ──→ 图鉴首次登记（KubeJS）／重复 3 换 1 兑换券
        ├─→ 垃圾/材料 ──→ 回收站 ──→ 武库点数（csgobox:armory_point）
        │
        ▼
武库点数 ──→ 军火商村民/终端机购买「更高级钥匙 / 终端货」
        │
        ▼
下一维度（下界/末地）──→ 挑战阶段 BOSS ──→ BOSS 专属箱 + 传说钥匙碎片
        │
        ▼
末地终局 ──→ 碎片锻造传说钥匙 ──→ 军械库宝箱（毕业箱）
```

**PvE 来源映射（写进箱子 `entity` 字段，原生机制，零脚本）**：

| 阶段 | 箱子来源实体/结构 | 说明 |
|---|---|---|
| 主世界 | 僵尸/骷髅/掠夺者等原版怪 + Dungeons Arise 地牢、dungeons-and-taverns | 基础箱 + 铁钥匙高掉率 |
| 下界 | 猪灵蛮兵/凋灵骷髅 + YUNG's 下界要塞 | 金钥匙箱；BOSS = Ignis |
| 末地 | 末影人/潜影贝/末地城 + Cataclysm Ancient Remnant、Harbinger | 钻石钥匙箱；BOSS 专属箱 |

### 4.2 每章任务链模板（任务条件与奖励草案）

> 任务 ID、依赖、条件在实施时落成 `config/ftbquests/quests/*.snbt`；下列为内容规格。

**章 0 序章（3 任务）**
1. 「领取启动包」：任务奖励 = `csgobox:csgo_key0 ×1` + 新手箱（直接 `csgobox` 物品或 `/give`，实施时用 FTB 物品奖励）

3. 「认识回收站」：条件 = 获得 `csgobox:armory_point` ≥1；奖励 = 弹药盒 ×…（TACZ）

**章 1 主世界（6~8 任务）**
- 「打怪掉箱」：条件 = 获得步枪箱/手枪箱各 1
- 「第一把皮肤枪」：条件 = 开出 grade≥3 的枪；奖励 = 铁钥匙 ×1
- 「军火商开业」：条件 = 找到 arms_dealer_hut（Explorer's Compass 找结构）
- 「新手毕业」：条件 = 累计开箱 ≥20 或图鉴登记 ≥3；奖励 = 金钥匙 ×1（进入下界的门票之一）

**章 2 下界（6~8 任务）**

- 「熔火挑战」：条件 = 击杀 `cataclysm:ignis`（Cataclysm 实体 id 实施时核对）；奖励 = **BOSS 专属箱** + 传说钥匙碎片① ×1（KubeJS 发奖或掉落）

**章 3 末地（6 任务）**
- 「钻石钥匙」：条件 = 拥有 `csgobox:csgo_key2`（45 点 + 1 钻石购买/任务奖励）

- 「远古回响」：条件 = 击杀 `cataclysm:ancient_remnant`；奖励 = 碎片② ×1

**章 4 终章（5 任务）**

- 「毕业」：条件 = 图鉴 6 系列全收集 + 军械库隐秘级皮肤枪；奖励 = 纪念物品/称号

## 5. 箱子规格（`config/csbox/*.json`）

### 5.1 命名与通用字段

- 文件名即箱子 ID，只允许小写/数字/`_`/`.`/`-`；本包统一 snake_case：`rifle_case.json`、`pistol_case.json`、`sniper_case.json`、`special_case.json`、`legend_case.json`、`armory_vault.json`、`boss_ignis.json`、`boss_remnant.json`、`boss_harbinger.json`、`terminal_*.json`。
- 每个普通箱：`"type": "csbox"`（或省略）+ `key` + `random: [625, 125, 25, 6, 4]`（默认，高保值） + `entity`（来源）+ `drop`（概率，默认 0.02~0.08，随阶段下降）+ `requires: ["tacz"]`（枪械相关全部加）。
- 终端机：`"type": "terminal"`，**禁止 `key` 字段**；售价走 `config/csbox/_prices.json`。

### 5.3 掉落配置约定

- 主世界普通怪掉步枪/手枪箱 + `csgo_key0`：`drop: 0.02~0.03`（打怪掉箱，保底靠地牢保底箱）。
- 下界/末地普通怪掉对应箱 + 钥匙：`drop: 0.01~0.02`；钥匙不直接进箱子池，主要走军火商/终端/任务。
- BOSS 箱：`entity: ["cataclysm:ignis", 0.35]` 等 ID/概率交替数组，BOSS 掉率显著高于普通怪。
- 保底：地牢结构每座必出 1 个保底箱（见 §8，数据包/LootJS 注入）。

### 6.3 `_prices.json` 草案

- 直接继承 `compat-packs/tacz-pack/_prices.json` 的 30 个枪械/弹药变体键（`id#变体`，如 `tacz:modern_kinetic_gun#tacz:ak47: 2000`），作为终端机基准价。
- 价格上限纪律：**任意单件回收所得（≤8 点）永远换不到 9 点铁钥匙**；皮肤枪（TACZ 枪）不进回收池（KubeJS `ArmoryRecycleEvent` 黑名单，防止高价值物品进点数经济）。
- 价格纪律（v2.1.0 无默认价回退）：**物品池里的每个 id 物品都必须在 `_prices.json` 定价**，否则装载器对该箱子直接报错；终端机只报价已定价物品。回收照旧 90%（向上取整）。

### 6.4 终局链（模块 3）

1. **传说钥匙碎片**：Ignis → 碎片①；Ancient Remnant → 碎片②（KubeJS 监听击杀/掉落或 FTB 奖励发放，推荐 FTB 任务奖励，防重复刷）。
2. **传说钥匙**：`kubejs:legend_key`，合成 = 碎片① ×1 + 碎片② ×1（KubeJS `ServerEvents.recipes` 或 CraftTweaker）。
3. **军械库宝箱**：`armory_vault.json`（免钥匙 BOSS 箱以外的唯一关键产出；也可放末地城保底 1 个）。
4. **毕业判定**：FTB Quests 终章任务 = 集齐 6 系列图鉴 + 开出军械库 g5 皮肤枪。

## 7. 图鉴收集线（模块 2，KubeJS + FTB Quests）

- **首次登记**：监听 `BoxOpenedEvent` 与 `TerminalBuyEvent`，把 `GunId`（TACZ NBT）写入 `global`/玩家持久 NBT 首次集合；重复获得不计数；未收集项在任务书显示「？」（防剧透，可选）。
- **3 换 1 兑换**：任意 3 把同系列皮肤枪 → 合成 1 张 `kubejs:armory_voucher`（KubeJS 配方 + 同系列检测）；兑换券在 FTB Quests 自选奖励中兑换**图鉴已解锁**的该系列皮肤枪。
- **收集任务**：每系列 1 个收集任务（N 件达成 → 点数/兑换券/配件奖励），6 系列完成解锁终章。

**1.20.1 实现要点**：
- KubeJS Forge 1.20.1 用 **`ForgeEvents.onEvent(...)`**（不是 NeoForgeEvents）。
- csgobox 1.20.1 事件类全限定名：`com.reclizer.csgobox.forge_1_20_1.event.BoxOpenedEvent` / `BoxOpeningEvent` / `TerminalBuyEvent` / `ArmoryRecycleEvent`（已核对 forge_1_20_1 源码，包名与此一致）。
- TACZ 枪 NBT 在 1.20.1 位于 **ItemStack 顶层 tag**：`stack.getTag().getString("GunId")`；脚本读取 `item.nbt?.GunId`（KubeJS 的 `ItemStack.nbt` 访问）。
- 事件在**服务端**触发；登记数据写 `global`（KubeJS 持久化）或玩家 `persistentData`。
