# CS2-Box 2.0.3 玩家更新日志（自 2.0.2）

2.0.3 发布于 2026-10-18，是一次跨平台一致性收口批次：修复两个影响服务器启动的崩溃（Cloth Config lambda、Create 机械手联动），补齐两个平台漏同步的批量开箱容量护栏，并带来一批网页配置工具的工作流增强。**不涉及配置文件格式**，存档与配置完全兼容。

六个平台同步发布：NeoForge（1.21.1 / 26.1.2 / 26.2）与 Forge（26.1.2 / 26.2 / 1.20.1）。

发布文件（按游戏版本选择）：

- `csgobox-1.21.1-2.0.3.jar` —— NeoForge / Minecraft 1.21.1
- `csgobox-26.1.2-2.0.3.jar` —— NeoForge / Minecraft 26.1.2
- `csgobox-26.2-2.0.3.jar` —— NeoForge / Minecraft 26.2
- `csgobox-forge-26.1.2-2.0.3.jar` —— Forge / Minecraft 26.1.2
- `csgobox-forge-26.2-2.0.3.jar` —— Forge / Minecraft 26.2
- `csgobox-forge-1.20.1-2.0.3-srg.jar` —— Forge / Minecraft 1.20.1（SRG 重映射版，生产必需）

## 修了什么（玩家可感知）

- **装了 Cloth Config 后专用服务器无法启动**（NeoForge 三平台）：Cloth 配置屏的注册代码里有个 lambda，虽然包在「仅客户端」守卫里，但会被连同签名一起编进模组主类；主类随后被事件总线反射扫描，专用服务器一解析到客户端界面类就崩溃。现在注册整体挪进一个只在「装了 Cloth 的客户端」才加载的持有类——守卫防得住执行防不住签名扫描，隔离类才是正解。Forge 三平台的同款潜伏隐患亦一并隔离，六平台模式统一。
- **没装 Create 时，1.21.1 / 1.20.1 服务器启动崩溃**：Create 机械手开箱联动的监听器此前在无 Create 环境直接把模组加载搞挂。现在只有检测到 Create 已安装才加载相应代码，无 Create 环境不再触发。
- **大批量开箱不再丢结果（1.21.1 / Forge 1.20.1）**：批量开箱结果分片的客户端待处理队列上限在这两个平台漏同步为旧值 64——开 6400 箱这种大批量时最旧约 4 千多份结果会被静默裁掉，合并弹窗缺数据。现在六平台统一为 256。
- **Forge 三平台批量单包护栏收紧对齐**：单包物品数上限从 1024 收紧为与 NeoForge 一致的 32（服务端对异常批量包的拒绝口径六平台一致）。
- **网页端 `#pack=` 导入不再越刷越多**：同一条 `/csbox editor` 链接此前每刷新一次网页，都会把 `config/csbox` 再导入一批新草稿（2→3→4→…），停留越久越卡。现在按文件名+内容指纹防重，刷新/重开同一链接不再重复导入。
- **`/csbox editor` 链接现在会自动带上你本地的箱子配置**：命令输出的链接内嵌 `config/csbox/*.json` 与 `_prices.json`（损坏的 JSON 原文也能带上，在导入框里就地修正后保存），同时把物品/生物注册表 id 同步进浏览器用于输入补全——在浏览器编辑箱子时无需再在游戏里逐个抄 id。配置只在你的游戏与浏览器之间流转，不会发往任何服务器；超长配置自动精简或回退纯链接。

## 新内容

- **网页配置工具大幅增强**：未知 id 校验（对照游戏注册表镜像，写了不存在的物品/生物/价格键会点名）；`#pack=` 导入冲突对话框（同名不同内容逐件询问覆盖/保留/跳过）；草稿徽标（来源游戏版本+保存时间）；`#workspace=` 整工作区分享链接；价格页新增 EV 期望值面板（逐档开箱期望值与拆解回收期望）；「应用到游戏」按钮（浏览器经 File System Access API 直接写回 `config/csbox/`，不支持的浏览器自动隐藏入口）。
- **`/csbox editor` 新增本地配置统计行**：输出链接前多一行「箱子数 / 物品条目数 / 未定价 id 数」，一眼看清本地配置规模。
- **终端机开场淡入（26.1.2）**：打开终端机屏幕新增 10 tick 黑场淡入，观感与 26.2 平台一致。

## 安装与升级

1. 加载器要求与 2.0.2 相同：NeoForge（1.21.1 → 21.1.248+，26.1.2 → 26.1.2.95，26.2 → 26.2.0.59）或 Forge（26.1.2-64.1.0 / 26.2-65.1.1 / 1.20.1-47.4.22）；
2. 把对应 jar 放进 `mods/`，直接替换旧版即可。存档与配置完全兼容，首次启动会自动更新为 v2.0.3 内置教程（离线复制到 `config/csbox/`，无需联网）。

配置格式与 2.0.2 完全一致，无需迁移。
