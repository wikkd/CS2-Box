# CS2 Box — 玩家简介

> 把 CS:GO 的武器箱开箱，搬进 Minecraft。当前版本 **1.0.6**。

CS2 Box 让你在 Minecraft 里体验 CS:GO 那种开箱抽奖的乐趣。不花真钱，游戏内用 `/give` 领箱子和
钥匙，右键看预览，把对应的钥匙放进去点开启，一段滚动揭晓动画后，结果停在属于你的战利品上。开箱
结果由服务端真随机决定，客户端只播动画，公平直接。

- **5 档稀有度**：消费、工业、军规、受限、保密，越稀有越难抽，权重可在 JSON 里调。
- **4 档钥匙**：铁、金、钻石、下界合金，最高档只能靠锻造台升级。
- **自定义箱子**：改 `config/csbox/*.json` 就能加新箱子，不用重新编译。
- **成就 & 命令**：首次开箱成就、累计开 200 箱的隐藏挑战，以及 `/csbox` 查看/重载配置。

**本版说明**：1.0.6 专注开箱核心玩法；批量开箱、终端机、军火商等都是 1.0.7/1.0.8 的功能，以后会加。

## 关于项目

本项目是原版 **CsgoBox**（作者 Reclizer）的重制维护版，当前由 ChloePrime 维护。相比原版：重做了
界面、修掉一个已知安全问题、把物品序列化改成不依赖 CraftTweaker，并改成多加载器（NeoForge
1.21.1 / 26.1.2 / 26.2，另有实验性的 Forge 版本）。采用 **MIT 许可**，可自由分支再分发，注明原作者
并附上仓库链接即可。

**说明：** 部分代码、贴图和文案由 AI 生成，发布前已人工核对。玩起来没问题，只是坦诚说明一下。
