## 归档规则（新增归档时遵守）

1. **只归档已确认废弃的内容**：头部已明确声明「已归档 / 历史快照 / 不再维护」、
   功能已被取代、或版本已过时且无活跃引用。
2. **不要归档用户在途工作**：git 状态为 M / A / ?? 的文件（正在修改或新增）一律不动。
3. 归档时使用 `git mv`（保留历史），并在文件顶部补统一横幅：
   `> ⚠️ 已归档（历史快照 · <日期>）：原位于 <原路径>，已移入 docs/archive/。……`
4. 归档后**修正所有活跃文档中的链接**（指向 `docs/archive/`），并更新本索引。
5. 本目录内文件不予更新；如需引用其内容，复制进新文档并注明出处。
