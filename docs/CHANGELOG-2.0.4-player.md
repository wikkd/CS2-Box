# CS2-Box v2.0.4 更新日志

发布日期：2026-11-08

## 新平台

- 新增 **Fabric 1.21.1** 与 **Forge 1.18.2** 支持，模组现覆盖 8 个平台：NeoForge 1.21.1 / 26.1.2 / 26.2，Forge 1.18.2 / 1.20.1 / 26.1.2 / 26.2，Fabric 1.21.1。
- 两个新平台均为完整移植：开箱、批量开箱、终端机、武库拆解台、军火商村民与全部 `/csbox` 命令照常可用，JEI / REI / Jade / Cloth Config 等按各版本可用性接入。
- 已知差异：
  - Fabric 1.21.1 暂无 Create 自动化与 The One Probe；
  - Forge 1.18.2 暂无 EMI / WTHIT / TOP，军火商小屋不会在世界中生成（合成武库拆解台放置后村民照常转职，交易与定价不受影响）；
  - 1.18.2 的 TACZ 联动为数据级（物品校验可用，无 3D 检视）。

## 联动：卓越前线（Superb Warfare）

- 装有卓越前线时，终端机报价、检视界面中的 SBW 枪械以真实 3D 模型展示，并按模型大小自动缩放（此前 IGLA 等长枪会溢出预览框数倍）。
- 附带示例箱子包（`compat-packs/superb-warfare-pack/`，服主可直接取用）。

## 玩法扩展（服主可配置，玩家可感知）

- **箱子档位不再固定 5 档**：可自定义档位数量（1~64 档）、名称、颜色与权重，开箱动画、概率展示与 JEI / REI / EMI 概率查询自动跟随；限量档位支持。
- 新增一批可选箱子设置（全部默认关闭，不配置则行为与旧版完全一致）：
  - **多钥匙**：配置一组钥匙，任一持有即可开箱；
  - **磨损区间**：掉落的耐久物品可限定磨损范围；
  - **单开奖励**：按几率双倍掉落，或额外获得一个箱子；
  - **全服播报**：开出指定档位以上物品时全服公告；
  - **时间窗**：箱子可限定开放起止时间；
  - **开箱费用**：开箱可额外消耗武库点数；
  - **首开保底**：每名玩家首次开箱必出指定物品；
  - **终端谈判参数**：谈判轮数、超时与价格倾向可调；
  - **自定义开箱音效**。
- 新命令 `/csbox upgrade`：手持箱子执行，消耗背包中指定数量的同款箱子，将其升档为指定的高阶箱子（全员可用）。

## 重要修复

- **批量开箱不再丢钥匙**：混合使用主钥匙与备用钥匙时，此前可能出现"钥匙被扣光却开箱失败"且不退还的情况，已修复。
- **不再白扣点数**：配置了开箱费用的箱子，在钥匙不在手或点数不足时，任何资源都不会被误扣。
- **权重填 0 的档位现在真的不出货**（此前填 0 仍按默认概率掉落）。
- **6 档以上的自定义箱子**：右键预览不再无限转圈；开出物品的档位印记正确（此前第 6 档以上被错标为第 5 档，影响拆解台门控、全服播报与成就）。
- **进服踢线修复**：配置了大量箱子（500+ 个定义）的服务器，玩家进服不再被踢线。
- **安全修复**：修复 Forge 1.20.1 / 1.18.2 上可被恶意客户端利用的漏洞（伪造同步包替换服务端箱子注册表）。建议所有服主尽快更新。
- **拆解台自动化复制漏洞修复**：自动化管道向空槽插入物品时不再复制出多余物品。
- **1.18.2 / 1.20.1 共享资源失效修复**：全部配方、成就、战利品表在这两个版本真正生效；军火商小屋在 1.20.1 现在可正常在世界中生成。

## 军火商经济修复

- key1 交易此前在部分版本永远无法成交（或实际售价远低于设计值），已修复。
- 铁收购价加上限，杜绝"卖铁换点数再买 key0"的套利刷点。
- 绿宝石改价现在正确生效；收购价回退值与动态定价对齐，切换定价开关不再跳价。

## 体验优化

- 修复死亡或重生后血条、热键栏、准星永久消失的问题（1.21.1 NeoForge / Fabric）。
- 终端机报价与对话文本不再溢出界面；报价物品 3D 预览按尺寸自动缩放。
- 修复部分英文界面乱码，补齐缺失的中文翻译。
- EMI 用户进服不再卡顿（箱子数据未变化时跳过刷新）。
- `/csbox reload` 后终端机购买不再报错。
- 批量开箱失败退款时保留物品上的改名等铁砧数据。
- 批量结果"收下"按钮点击区域对齐。
- 大箱子开箱与悬停概率展示更流畅（性能优化）。

## 终端机新外观

- 终端机物品模型重制：四元素售货亭造型，屏幕与徽标采样真实素材，体积缩小约一半，展示框内比例与贴图修正。

## 移除

- **本地教程改为纯在线版**：`config/csbox/` 不再生成教程文件，通过 `/csbox help` 的可点击链接或模组详情页 Website 按钮打开在线教程（历史遗留的 `_tutorial_*.md` 可手动删除）。
- **移除 `/csbox tacz` 命令**：TACZ 物品与变体 id 查询改用 `/csbox editor` 打开的网页配置工具（自动补全 TACZ 物品）。
