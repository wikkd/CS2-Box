## 2. 已实施：terminal_dot_tile 极致降采样

- **发现**：512×512 纹理实为「2×2 白点（alpha 22）每 24px 一个」的周期网格；程序验证
  24×24 是数学最小平铺周期（无更小周期）。
- **改动**：
  - 纹理 `terminal_dot_tile.png` 512² → 24²（2,191 B → 98 B）
  - 四平台 `TerminalChatRegion.drawDotGrid`：period 8 → 24；blit 纹理尺寸参数 512 → 24
  - `TerminalAssetsTest` 尺寸断言 512 → 24
  - `scripts/gen-terminal-assets.py` 生成器同步 24×24（保证可复现）
- **附带修复**：旧代码把整张 512 纹理缩进 8px 格渲染（实际是糊成一团的细点或空白），
  与 HTML 原型 `radial-gradient(...) 0 0 / 24px 24px` 的 24px 点阵设计不符；新渲染 1:1 平铺
  恢复设计意图。
- **收益**：解码内存 1,048,576 B → 2,304 B（-455×）；磁盘 2,191 B → 98 B；
  400×200 区域 blit 次数约 1,250 → 140。
- **验证**：24×24 平铺重建与原 512 图逐像素一致；`:common:test` 通过；
  `:v26_1_2:compileJava` 通过（v1_21_1 因本机缺 TACZ 依赖未验证，见 §5）。

## 3. 死代码扫描（扫描完成，未删除）

方法：根集（`@Mod` ×4、`@EventBusSubscriber`、JUnit 测试共 34 个）BFS 可达性分析，
按 Java import 遮蔽语义判定（平台 `BoxJsonLoader` import common 版后，同包平台副本即被遮蔽）。

结果：336 个 Java 文件 → 322 可达 → **14 个死类候选，共 1,679 行**。

### A 类：孤儿镜像副本（12 文件 / 1,404 行，可安全删除）

四平台各一份，common 已有同逻辑且平台 loader 实际使用 common 版：

| 文件（每平台一份） | 行数 | 说明 |
|---|---|---|
| `box/BoxJsonSchemaValidator.java` | 134 | `BoxJsonLoader.java:10` import 的是 common 版 |
| `box/TutorialFetcher.java` | 90 | 平台侧无任何 import |
| `box/TutorialSources.java` | 127 | 平台侧无任何 import |

平台副本内容与 common 版已漂移（md5 不一致）——镜像纪律要防的典型遗留。
删除后每平台 jar 少 3 个类。

### B 类：common 零引用工具（1 文件 / 189 行，待定）

`common/.../utils/EntityChineseMap.java`：历史为 `ec18a50 refactor(common):
EntityChineseMap 迁 common — 9 平台去重 (B 类迁移 #1/6)`，迁入后无任何消费方。
可能是预留代码——删或留由功能规划决定。

### C 类：forge 同步缺口（1 文件 / 86 行，非删除问题）

`forge_26_1_2/.../villager/ModVillagers.java` 存在但 forge 入口从未接线：
v26_1_2 `CsgoBox.java:161` 有 `ModVillagers.register(modEventBus)`，forge 没有。
