# CS2-Box 2.0.4 玩家更新日志（自 2.0.3）

2.0.4 发布于 2026-11-08，是一次平台大扩张批次：**新增 Fabric 1.21.1 与 Forge 1.18.2 两个平台**（支持平台总数 6 → 8），箱子**档位与一批玩法开放配置**，并修复 Forge 老平台数据包内容不生效与一批军火商经济问题。

**配置格式向后兼容**：2.0.3 的箱子配置、价格表与存档直接可用；本版全部新字段都是可选的，不写就是原来的行为。

- `csgobox-26.1.2-2.0.4.jar` —— NeoForge / Minecraft 26.1.2
- `csgobox-26.2-2.0.4.jar` —— NeoForge / Minecraft 26.2
- `csgobox-fabric-1.21.1-2.0.4.jar` —— **新平台** Fabric / Minecraft 1.21.1（需 Fabric Loader + Fabric API）
- `csgobox-forge-1.18.2-2.0.4-srg.jar` —— **新平台** Forge / Minecraft 1.18.2（SRG 重映射版，生产必需）
- `csgobox-forge-1.20.1-2.0.4-srg.jar` —— Forge / Minecraft 1.20.1（SRG 重映射版，生产必需）
- `csgobox-forge-26.1.2-2.0.4.jar` —— Forge / Minecraft 26.1.2
- `csgobox-forge-26.2-2.0.4.jar` —— Forge / Minecraft 26.2

## 新平台

- **Fabric 1.21.1（首发）**：功能完整——开箱 / 批量开箱 / 终端机 / 武库拆解台 / 村民交易 / `/csbox` 全部子命令；JEI / REI / EMI / Jade / WTHIT / Cloth Config / Mod Menu 全部接入；安装 TaCZ: Refabricated 后可用检视视口与 3D 枪械渲染。已知差异：1.21.1 Fabric 无 Create 与 The One Probe 构建，对应联动不提供。
- **Forge 1.18.2（首发）**：功能完整；JEI 10.x / REI 8.x / Jade / Cloth Config 接入；TACZ 为数据级联动（物品校验）。已知差异：EMI / WTHIT / The One Probe 无 1.18.2 构建不提供；1.18.2 引擎不支持数据包驱动的结构生成，**军火商小屋不在世界生成**——合成军火拆解台放置后村民照常转职，功能不受影响。

## 新内容

- **档位可自定义（`grades`）**：箱子配置新增可选顶层 `grades` 数组（从低到高），整体替代固定五档——每档的 id、名称、颜色、权重、限量都能自己定，档数不限；不写 `grades` 就是原来的 5 档。在线配置编辑器（`/csbox editor`）同步支持。
- **玩法字段一批（全部可选，不写 = 旧行为）**：
  - `keys`：一个箱子接受多种钥匙（任一匹配即可开）
  - `wear:[min,max]`：开出的耐久物品按磨损区间扣损
  - `bonus`：单开奖励——按几率双倍掉落，或额外再送一个箱子
  - `announce_above`：开出指定档位以上的物品时全服播报
  - `available_from` / `available_until`：箱子上架 / 下架时间窗
  - `open_cost`：开箱额外消耗武库点数
  - `pity.first_open`：每个玩家的首次开箱保底
  - `negotiation`：终端机谈判轮数 / 超时 / 价格偏置（服务端配置）
  - `/csbox upgrade`：把手中的箱子升档为指定的高级箱（消耗指定数量）
  - `sound`：自定义开箱音效
  - `hide_odds` / `allow_bulk`：隐藏概率行 / 关闭批量开箱
- **卓越前线（Superb Warfare）联动**：安装 SBW 后，其枪械在箱子与检视中显示真实 3D 模型（1.21.1 / 1.20.1 / Fabric 1.21.1）；配套示例箱 `compat-packs/superb-warfare-pack/`。

## 变更（升级注意）

- **教程改为纯在线版**：模组不再内置教程，`config/csbox/` 也不会再生成 `_tutorial_v*.md` 文件（旧版本落盘的教程文件不会自动清理，可手动删除）。配置参考通过 `/csbox help` 的「在线教程」链接或模组列表里的 Website（地球）按钮打开。模组本身依旧零联网。
- **`/csbox tacz` 子命令移除**：查 TACZ 物品 id 改用 `/csbox editor`——网页编辑器的物品自动补全会带上服务器实际加载的全部 `tacz:*` 条目（枪械/弹药/附件），第三方枪包不用再猜 ID。`/csbox help` 同步补上 `validate` / `upgrade` 两行说明。

## 修了什么（玩家可感知）

- **Forge 1.20.1 / 1.18.2 数据包内容此前不生效**：1.21 改版了数据包目录名（复数→单数），随模组共享的钥匙等 7 个**合成配方**、多数**进度成就**（1.20.1 此前仅有 3 个生效）、军火商小屋**战利品表与结构**（1.20.1）在这两个平台一直没能加载。本版起按各版本目录规则正确打包：1.20.1 军火商小屋自此可在野外生成，1.18.2 的终端机成交 / 破产成就也已注册。
- **权重写 0 的档位照样出货**：配置里把某档权重写成 `0` 想砍掉该档，实际却被悄悄回填成默认权重继续出。现在写 0 就真的不出。
- **Create 机械手开箱偶发不出产物**：修复结果物品在一条内部路径上被原版背包接口的消费语义吞掉的问题。
- **物品标签（`#tag`）引用解析修复**：解析错误不再影响同一箱子里的其他标签条目；裸 `#` 写法按 NBT 字符串语义处理。
- **英文界面乱码修复**：部分英文文本此前显示为双重转义的乱码序列，已修复；补齐缺失的中文翻译键。
- **军火商经济三连修**：铁收购价与 key0 锚价结构性挂钩（改价格表不再能把村民变成印钞机）；key1 动态定价在部分平台的报价超过 64 点上限导致**永远无法成交**（改为「点数 + 金锭找零」双输入报价）；绿宝石直接定价此前被忽略（服主改价不生效）。
- **死亡/重生后 HUD 永久消失（1.21.1 与 Fabric）**：开箱动画或检视期间死亡 / 断线重进，血条、准星、热键栏不再消失。
- **Forge 1.20.1 / 1.18.2 安全修复**：恶意客户端此前可伪造服务端数据包（如「箱子注册表全量同步」）让服务端按伪造数据行事；现所有网络包都校验方向，伪造包会直接断开连接。
- **批量开箱不再吞钥匙**：同时持有主钥匙和任一备选钥匙（`keys` 字段）时批量开箱，此前可能把主钥匙扣光后报失败——箱子退回但钥匙不退；现先清点后扣减，任何情况下不会白损。
- **开箱不再白扣资源**：配置了 `open_cost` 的箱子，此前「有点无钥」会白扣点数、「有钥无点」会在别的实现上白扣钥匙；现开箱前先确认点数充足再动任何东西——余额不够直接拒绝，钥匙与点数都不会损失。
- **终端机购买崩溃修复**：管理员在谈判期间重载或删除该终端配置后继续购买，此前会报错且库存已被扣——现安全拒绝、不扣任何东西。
- **EMI 装机进服不再卡顿**：装 EMI 的客户端此前每次进服务器都触发数秒全量资源重载（哪怕箱子配置没变）；现内容没变就跳过。
- **超大箱子预览修复（全平台）**：单箱物品数超过 256、或档位数超过 5 的箱子，右键预览此前会一直转圈（部分平台）；现显示前 256 个物品、支持最多 64 档。
- **第 6 档及以上物品的档位修复（全平台）**：自定义档位超过 5 档的箱子，第 6+ 档的物品此前开出来会被错标成第 5 档（拆解台不认、播报与成就按错档）；现携带真实档位，拆解台可正常回收，开箱动画的框色改用「稀有特例」金色（此前不可见）。
- **进服踢线修复（注册表很大的服务器）**：配置了 513 个以上箱子的服务器，玩家此前进服会被直接断开连接（部分平台）；现已正常同步。
- **「收下」按钮点击区修正**：批量开箱总览的「收下」按钮部分区域此前点不中。
- **价格表超大数值**：`_prices.json` 里写超过 21 亿的价钱此前会变成负数；现按非法条目报错提示。
