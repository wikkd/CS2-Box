# CS2-Box · Forge 版 1.0.6 玩家更新日志

- **适用平台**：MinecraftForge 26.1.2（Java 25）
- **发布文件**：`csgobox-forge-26.1.2-1.0.6.jar`
- **发布说明**：Forge 平台随 1.0.6 发行线纳入发行，与 NeoForge 多平台版本功能一致。

## 安装

1. 安装 MinecraftForge 26.1.2（要求 Java 25）；
2. 将 `csgobox-forge-26.1.2-1.0.6.jar` 放入游戏目录的 `mods/` 文件夹；
3. （可选）安装 Blur 模组后，开箱相关界面的背景模糊自动生效。

## 核心玩法

- **CS:GO 风格开箱**：5 档稀有度分级，开箱结果由服务端授权随机，客户端播放滚动揭晓动画
- **4 把钥匙梯度**：铁 / 金 / 钻石 / 下界合金钥匙；下界合金钥匙仅可通过锻造台升级获得
- **按磨损值扣耐久**：抽出的物品按磨损值损耗耐久，查看界面显示实际扣损率，不会碎裂
- **成就与排行榜**：主动开箱累计自定义统计 `csgobox:opened_box`，可用原版记分板命令创建排行榜
- **动态箱子 JSON**：`config/csbox/*.json` 即可新增箱子类型，无需重新编译
- **教程自动下载更新**：首次启动自动生成示例箱子并附带图文教程
- **JSON 加载错误提示**：配置文件出错时在游戏中红色提示，不再静默失败

## 本版同步内容

- **批量开箱**：Shift + 右键箱子进入批量总览，二次确认后以流水面板展示全部开箱结果
- **终端机**（`csgobox:terminal`）：与军火商多轮谈判交易，含倒计时、打字动画、磨损档位报价，支持批量上限设置与 3D 检视预览
- **军火商生态**：武库点数（`csgobox:armory_point`）可兑换钥匙；武库拆解台回收物品获得武库点数；新增军火商村民职业（带专属交易）
- **高级箱**（`csgobox:premium_supply_box`）：军火商高级箱
- **Blur 模组软兼容**：安装 Blur 后主屏 / 出货屏 / 批量屏等背景自动模糊；未安装时按原版模糊选项显示
- **`/csbox nbt hand`**：任意玩家可查看手中物品的 NBT JSON，可直接用于配置箱子

## 修复

- **物品不再显示紫黑棋盘格**：箱子 / 钥匙等模组物品补齐模型定义，不再出现"没有模型"的紫黑贴图。
- **开箱箱子渲染修复**：开箱屏中央箱子改为高清 3D（PIP）渲染，放大查看清晰、有立体感，不再是像素贴图。

## 已知说明

- Forge 版为实验平台，与 NeoForge 版（1.21.1 / 26.1.2 / 26.2）功能一致，但互不通用（不同 mod 加载器）。
