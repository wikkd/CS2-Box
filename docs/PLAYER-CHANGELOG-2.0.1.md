# CS2-Box 2.0.1 玩家更新日志（自 2.0.0）

2.0.1 发布于 2026-09-13，是 2.0.0 的完善与增强版：开箱信息全面可查、抽奖算法与配置严格对齐、命令和教程入口更顺手，并修复了一批联机与 Forge 1.20.1 的稳定性问题。2.0.0 的终端机谈判、武库商小屋、批量开箱等玩法全部保留。

六个平台同步发布：NeoForge（1.21.1 / 26.1.2 / 26.2）与 Forge（26.1.2 / 26.2 / 1.20.1）。

发布文件（按游戏版本选择）：

- `csgobox-1.21.1-2.0.1.jar` —— NeoForge / Minecraft 1.21.1
- `csgobox-26.1.2-2.0.1.jar` —— NeoForge / Minecraft 26.1.2
- `csgobox-26.2-2.0.1.jar` —— NeoForge / Minecraft 26.2
- `csgobox-forge-26.1.2-2.0.1.jar` —— Forge / Minecraft 26.1.2
- `csgobox-forge-26.2-2.0.1.jar` —— Forge / Minecraft 26.2
- `csgobox-forge-1.20.1-2.0.1-srg.jar` —— Forge / Minecraft 1.20.1（SRG 重映射版，生产必需）

## 安装与升级

1. 加载器要求与 2.0.0 相同：NeoForge（1.21.1 → 21.1.248+，26.1.2 → 26.1.2.95，26.2 → 26.2.0.59）或 Forge（26.1.2-64.1.0 / 26.2-65.1.1 / 1.20.1-47.4.22）；
2. 把对应 jar 放进 `mods/`，直接替换旧版即可。存档和配置兼容，首次启动会自动更新为 v2.0.1 内置教程（离线复制到 `config/csbox/`，无需联网）；
3. ⚠️ **服主升级注意（箱子注册表解耦，联机修复，破坏性调整）**：
   - 自定义箱子不再用 `/give csgobox:<箱子名>` 发放，改用 **`/csbox give <玩家> <箱子> [数量]`**；
   - 旧版本中「自建箱子」发放过的物品 id 会失效，需要服主用 `/csbox give` 重新发放一次；
   - 原版自带箱子（csgobox 默认箱子）不受影响，旧存档照常可用；
   - 联机不再要求客户端与服务端 `config/csbox/` 完全一致，配置可自由增删并热重载。

## 本版新增

### 开箱概率全面可查

- **箱子上限提示**：物品 tooltip 直接带 5 档稀有度概率行（默认只列物品，按 **F3+H** 打开原版高级提示框即可看到）；
- **JEI / REI / EMI 分类查询**：每个箱子的档位权重、单件概率，任意物品反查出自哪个箱子，全部与服务端实际抽取同一套算法。平台组合：NeoForge 1.21.1 = JEI+REI+EMI，NeoForge 26.1.2 / 26.2 = JEI+REI，Forge 1.20.1 = JEI+REI+EMI（Forge 26.x 暂无 JEI/REI/EMI 构建）；
- **准星信息**：Jade / WTHIT / The One Probe 指向地上的箱子时直接显示掉落率与 5 档概率（WTHIT 六平台，Jade/TOP 覆盖 NeoForge 三平台 + Forge 1.20.1）；
- **`/csbox info` 来源模组统计**：一眼看出当前所有箱子「开得出哪些模组的货」（方便确认联动数据包已生效）。

### 抽奖算法完善

- **概率与配置一致**：给物品配置了档内 `weight` 的箱子，所有面板（tooltip / JEI / REI / EMI / info）都按真实权重显示，不再出现「显示 20% 实际 5%」的偏差；`weight<=0` 的条目显示 0%，不会抽到；
- **全零权重箱子拒绝开启**：五个档位权重全部为 0/负（或缺失）的箱子，在掷骰前直接拒绝，不消耗钥匙和箱子（旧行为会静默掉到 1 档）；
- **开箱保底（pity）**：箱子 JSON 可加可选字段 `"pity": { "grade": "classified", "every": 20 }`——连续 `every-1` 次开出低于目标档后，下一次强制从目标档及以上加权抽取，命中即重置。按「玩家 × 箱子」独立计数，单开和批量开箱都生效（计数随服务器重启清零）。

### 命令更顺手

- **`/csbox help` 全员可用**（不再要求 OP），并直接给出一键链接：「打开教程文件夹」（打开 `config/csbox/`，内置教程就在里面）与「在线教程」（浏览器打开 Gitee）；网页配置工具入口并入同一帮助；
- **`/csbox give <玩家> <箱子> [数量]`**：服主向玩家发放指定箱子（替代旧的 `/give csgobox:xxx`）；
- **`/csbox validate`**：干跑校验所有箱子配置，配错即时发现，不重启也能排错；
- **`/csbox nbt hand`**：新增「点击复制完整 JSON」按钮，一键复制手里的配置；
- **`/csbox tacz list`**（装 TACZ 时）：浏览已加载枪械/弹药/附件的真实 id，给配置箱子的作者用；
- **`/csbox editor`**：全员可打开网页版配置编辑器（与 `/csbox help` 中链接同一地址）。

### 终端机与拆解台

- 终端机支持**价格表、库存与补货**（`stock` / `restock_minutes`）、**折扣**（`discount`）等经济配置；报价物品可 3D 拖拽检视，TACZ 枪械支持检视联动；
- **拆解台修复**：单开箱产物现在完整携带稀有度标记，可以进拆解台回收；拆解台输入/输出槽改持久化，区块重载不再丢物品。

### 机械动力（Create）联动（NeoForge 1.21.1 / Forge 1.20.1）

- **机械手自动开箱**：机械手手持对应钥匙、侧面指向传送带/置物台上的箱子即可直接开箱，产物可被传送带/机械臂运走；无钥匙的箱子空手也能开；
- 真玩家手持钥匙右键台上的箱子同样开箱（产物进背包）；
- 拆解台也可接入自动化（产量可被脚本控制，双倍回收等）。

### 给整合包作者

- **配置表达力**：档内物品 `weight`、`count:[min,max]` 区间、`#tag` 标签引用、`loot_table` 战利品表、随机附魔、每箱 `icon`、`requires` / `enabled` 门控；
- **联动生态**：`compat-packs/` 提供 Apotheosis / Iron's Spells / TACZ 官方示例箱配置；`scripts/add-biome.py` 与 `docs/examples/biome-datapack/` 演示如何把武库商小屋接入自定义群系/村庄；
- **KubeJS 事件**：新增 `TerminalBuyAttemptEvent`（终端机购买前可取消：限购/黑名单/门槛）与 `BoxEntityDropEvent`（实体掉落箱子前可取消/调概率），以及 `ArmoryRecycleEvent.setYield`（回收产量重定价）；
- **校验工具**：`box.schema.json` 结构校验 + `/csbox validate` 干跑 + `scripts/boxgen.py` / `scripts/check-ids.py`；
- **服务器配置收窄**：移除所有玩家向/开发向配置项，只保留 7 个服务端项（详见 `docs/CONFIGURATION.md`）。

## 重要修复

- **Forge 1.20.1 SRG 崩溃修复**：生产 jar 改用 `renameJar` SRG 重映射产物（`-srg.jar`），修复了 `NoSuchMethodError`（`CriteriaTriggers.register`）崩溃——1.20.1 玩家务必使用 `-srg.jar`；
- **单开动画与实得一致**：动画滚动条结果与最终发放奖品不再错位；
- **联机配置不同步修复**：箱子定义由服务端全量同步（Forge 三平台补齐），配合注册表解耦，两端配置不一致不再导致问题；
- **隐私**：日志不再记录玩家名；
- **服务器稳定性**：批量开箱任务队列改有界（高峰不再无界积压）；
- 检视物品返回后终端机屏幕不再失联；终端机稀有度档位名称与开箱档位统一。

## 保持不变

2.0.0 的玩法原样保留：5 档稀有度分级、多把钥匙（含锻造台升级路线）、批量开箱、终端机谈判、武库商小屋与村庄生成、成就与统计、JSON 箱子配置、开箱动画与 3D 拖拽预览。
