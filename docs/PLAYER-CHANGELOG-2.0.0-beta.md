# CS2-Box 2.0.0-beta 玩家更新日志（自 1.0.6）

2.0.0-beta 发布于 2026-08-22。1.0.6 之后新增的核心内容：终端机谈判玩法、批量开箱恢复（含 UI 打磨）、武库商小屋与村庄生成、JEI 开箱概率查询。原计划的 1.0.7 / 1.0.8 开发线不再单独发行，全部合并进本版本。

本版本 6 个平台全部纳入正式发布：NeoForge（1.21.1 / 26.1.2 / 26.2）与 Forge（26.1.2 / 26.2 / 1.20.1）同步发行。

发布文件（按游戏版本选择）：

- `csgobox-1.21.1-2.0.0-beta.jar` —— NeoForge / Minecraft 1.21.1
- `csgobox-26.1.2-2.0.0-beta.jar` —— NeoForge / Minecraft 26.1.2
- `csgobox-26.2-2.0.0-beta.jar` —— NeoForge / Minecraft 26.2
- `csgobox-forge-26.1.2-2.0.0-beta.jar` —— Forge / Minecraft 26.1.2
- `csgobox-forge-26.2-2.0.0-beta.jar` —— Forge / Minecraft 26.2
- `csgobox-forge-1.20.1-2.0.0-beta.jar` —— Forge / Minecraft 1.20.1

## 安装与升级

1. 安装对应版本的加载器：NeoForge（建议 Java 21 及以上），或 Forge（26.1.2-64.1.0 / 26.2-65.1.1 / 1.20.1-47.4.22，Java 17 及以上）；
2. 把对应 jar 放进游戏目录的 `mods/` 文件夹，直接替换旧版即可，存档和配置兼容；
3. 可选：装 Blur，开箱界面背景自动模糊，模糊半径可在模组配置里调；
4. 可选：装 JEI，解锁开箱概率查询（仅 NeoForge 三个平台）。

## 新增内容

### 终端机

1.0.6 正式版没有终端机（当时还在开发），这是 2.0.0 的新玩法：用武库点数向军火商谈判购买开箱物品。

- 右键终端机开始谈判，最多 5 轮报价。每轮可以长按「接受」成交，或长按「拒绝」等下一轮；
- 报价带随机磨损值：有耐久的物品按磨损扣耐久；没有耐久的物品，磨损折算成加价（每 5% 磨损加 1 武库点数，最多 +20）；
- 打开终端后开始 3 小时倒计时。按世界运行时间计，暂停游戏和关服不计时，重启后续算；
- 成交、5 轮全拒、超时，三种结局都会销毁终端机物品。一台一次性，用完要再弄一台；
- 中途关闭再打开，对话、报价和轮次与上次离开时一致；
- 正在谈判的终端机转给别人，对方无法交易，只会收到「去问问 xx 吧」；
- 支持批量购买（上限可选 30 / 64 / 200 / 400 / 800 / 无上限）和 3D 拖拽检视报价物品；
- 不需要钥匙。

### 武库商小屋与村庄生成

1.0.6 已有军火商村民、武库点数和拆解台。2.0.0 补上了世界生成部分：

- 野外新增武库商小屋结构，屋内有军火商、武库拆解台和一个商店宝箱（武库点数、基础箱、铁钥匙、绿宝石、铁锭）；
- 平原、沙漠、热带草原、雪地、针叶林五种村庄会沿街道自然生成武库商小屋；
- 军火商村民做了防解雇、防消失加固。

### JEI 开箱概率查询

- 安装 JEI 后可查看每个箱子的掉落率、各稀有度权重和单件概率，与服务端实际算法一致；
- 任意物品可反查哪个箱子掉落、概率多少；
- 多人服务器的客户端同样可用，箱子定义由服务端自动同步。

### TACZ 枪械第一人称检视（1.21.1 / 1.20.1 版）

安装《永恒枪械工坊：零》后，抽中的 TACZ 枪械可进入独立的第一人称检视屏，播放检视动画。未安装 TACZ 时无影响。

### 给整合包作者

新增三个事件，支持 KubeJS 脚本监听：

- `BoxOpeningEvent`：开箱前触发，可取消（适合做权限门槛、每日限量）；
- `TerminalBuyEvent`：终端机成交后触发；
- `ArmoryRecycleEvent`：拆解台前触发，可取消（适合做物品黑名单）。

用法示例见仓库 `docs/KUBEJS-EVENTS.md`。

## 变化

### 批量开箱（恢复 + UI 打磨）

1.0.6 屏蔽了批量开箱入口，本版本恢复并打磨：Shift + 右键箱子进入批量总览屏，点「开启」直接开箱（已删除二次确认屏，扣减与库存复核仍由服务端权威执行），结果以流水屏展示。单次上限由服务端配置 `bulkOpenCount` 控制（0 为无上限）。

本版对批量开箱界面做了一轮客户端打磨（六平台同步）：

- 揭晓屏打开期间自动隐藏 HUD，关闭后恢复；
- 流水播放期间提供 **CLOSE** / **SKIP** 按钮（奖励已发放，不会丢东西）；
- 3D 预览区缩小重排，旋转模型不再溢出压住信息行；
- 总览屏信息行按预览区位置动态排布，标题居中；
- **「显示全部」网格可滚动**：图标缩小、间距加大，用**滚轮 / ↑↓ 方向键**浏览全部合并条目，右侧有滚动条指示，内容溢出时提示「滚轮 / ▲▼ 浏览」，不再截断 64 项、也不会被「收集」按钮遮挡。

### 终端机配置

- 首启不再生成默认的 `terminal.json`。创造栏拿到的终端机默认是空的，需要自建 `terminal.json`（声明 `"type": "terminal"`）才能配置谈判奖池；
- 已有的 `terminal.json` 会自动迁移（补上 `"type": "terminal"`、删除废弃的 `key` 字段），不需要手动改；
- 手写的终端配置如果缺 `type` 字段，会拒绝加载并在游戏内报错。

### 其他

- 教程文档随版本更新为 `_tutorial_v2.0.0-beta*.md`，首次启动自动下载新版、清理旧版；
- jar 文件名改为 `csgobox-<MC版本>-2.0.0-beta.jar`（Forge 为 `csgobox-forge-<MC版本>-2.0.0-beta.jar`）。

## 修复

- 关闭终端机屏幕不再影响玩家 F1 隐藏 HUD 的状态；
- 长按「接受 / 拒绝」后拖出按钮再松手，不再误触发；
- 快速切换两台终端机时，旧会话数据不再串到新屏幕；
- 开屏瞬间切热栏或死亡等异常情况不再导致屏幕空白挂着，5 秒无响应自动关闭；
- 批量开箱在异步计算期间库存发生变动时，不再导致整批失败；
- 已销毁的终端机流转到其他人手里，再次打开会当场清理，不残留会话；
- 流水结果屏「收集」按钮原先 Forge 分支渲染位置与点击判定错位，已统一修正。

## 保持不变

1.0.6 的功能原样保留：5 档稀有度开箱、4 把钥匙（下界合金钥匙仅锻造台升级）、按磨损扣耐久、开箱成就与统计、动态箱子 JSON 配置、`/csbox` 命令、教程文档、开箱揭晓动画与 3D 拖拽预览。
