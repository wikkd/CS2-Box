# CS2-Box 2.0.2 玩家更新日志（自 2.0.1）

2.0.2 发布于 2026-09-17，是一次全项目体检后的修复批次：修好了两个影响核心玩法的功能缺陷（批量开箱上限、拆解台高价值物品），并**移除了终端机补货设定**（`restock_minutes`），同时把 2.0.1 之后的新功能（村民动态定价、报价上限动态档位、Create 机械手开箱等）一并发行。

六个平台同步发布：NeoForge（1.21.1 / 26.1.2 / 26.2）与 Forge（26.1.2 / 26.2 / 1.20.1）。

发布文件（按游戏版本选择）：

- `csgobox-1.21.1-2.0.2.jar` —— NeoForge / Minecraft 1.21.1
- `csgobox-26.1.2-2.0.2.jar` —— NeoForge / Minecraft 26.1.2
- `csgobox-26.2-2.0.2.jar` —— NeoForge / Minecraft 26.2
- `csgobox-forge-26.1.2-2.0.2.jar` —— Forge / Minecraft 26.1.2
- `csgobox-forge-26.2-2.0.2.jar` —— Forge / Minecraft 26.2
- `csgobox-forge-1.20.1-2.0.2-srg.jar` —— Forge / Minecraft 1.20.1（SRG 重映射版，生产必需）

## 修了什么（玩家可感知）

- **大箱子悬停不再卡顿、清单不再顶出屏幕**：箱子 tooltip 此前悬停期间每帧重新构建全部内容（高级提示模式下还要逐物品算概率），且物品清单不截断——满配大箱子既浪费性能又把 tooltip 顶出屏幕。现在构建结果会缓存，清单每档最多显示 8 行并附「…等 N 件」，完整清单仍可经 `/csbox info` 和 JEI/REI 概率表查询。
- **保底进度现在看得见了**：配置了保底（pity）的箱子，开箱预览屏会显示「保底：还差 N 次」——此前保底只在后台默默计数，玩家完全感知不到。
- **批量开箱尊重每箱上限**：配置了 `max_per_player` 的箱子，此前可以用批量开箱一次性清空整个配额（囤 50 个一把全开）。现在批量开箱严格裁剪到剩余额度，达到上限后照常提示。
- **拆解台不再卡死高价值物品**：价值超过 64 点的物品（回收产出高于一个输出槽堆叠上限）此前进度条走满却不产出、物品卡在机器里。现在产出会分批流入输出槽，任意价额物品都能正常拆解。
- **批量开箱失败立刻反馈**：此前少数失败情况（如箱子/钥匙不足的边界态）客户端进度屏要空等 10 秒，现在立即收到拒绝提示。
- **配置拼写错误会被点名**：箱子 JSON 里写了不存在（或已废弃）的字段，加载时会明确提示「未知字段」——此前会无声地按默认值加载，排查极难。只是提示，不阻断加载。

## 移除的设定（服主注意）

- **终端机补货 `restock_minutes` 已删除**：该设定为误加，从未进入需求清单。现在配置了 `stock` 的终端机卖空后保持空态直到服务器重启（库存是内存态，重启即回满）——这是 `stock` 字段的原始文档行为。**如果你的箱子 JSON 里写了 `restock_minutes`，升级后 `/csbox validate` 会报错，把该行删掉即可**，其余字段不受影响。

## 新内容（2.0.1 之后堆积，一并发行）

- **军火商村民动态定价**：村民的收购价与钥匙售价锚定 `config/csbox/_prices.json` 价格表，可在 `_villager_prices.json` 调整浮动幅度，不再写死。
- **终端机报价上限改为动态档位**：上限档位按价格表实际价额自动生成，不再固定为旧档位。
- **Create 机械手开箱走官方配方 API**（1.21.1 / 1.20.1），修复装配成功却无产出的情况。
- 一批配置解析与渲染修复（TACZ 弹药/附件、无 TACZ 环境终端机渲染崩溃、配方 key 格式、Forge 26.x 3D 拖拽方向等），详见 `CHANGELOG.md`。

## 安装与升级

1. 加载器要求与 2.0.1 相同：NeoForge（1.21.1 → 21.1.248+，26.1.2 → 26.1.2.95，26.2 → 26.2.0.59）或 Forge（26.1.2-64.1.0 / 26.2-65.1.1 / 1.20.1-47.4.22）；
2. 把对应 jar 放进 `mods/`，直接替换旧版即可。存档和配置兼容，首次启动会自动更新为 v2.0.2 内置教程（离线复制到 `config/csbox/`，无需联网）；
3. 正在使用的限库存终端会重新记满库存（库存状态仍在内存中，重启即重置——这是既有文档行为，本版未改变）。

除上述 `restock_minutes` 字段外，配置格式与 2.0.1 完全一致，无需迁移。
