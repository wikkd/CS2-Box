原版容器 GUI 原型 · 说明

  • 面板为原版容器样式（灰面板 + 内凹槽位），后续 Java 落地用 AbstractContainerScreen + 原版 container 纹理即可。
  • 投料口：1 格输入槽（与漏斗投喂共用同一格，呼应贴图顶部投料口）。
  • 拆解按钮：放入带品级物品后按钮亮起，点击执行回收并发放 +N 武库点数（对齐 GDD「+N 点数」正反馈）；不可回收物按钮保持禁用。
  • 无钱包：武库点数是实物，拆解后直接进玩家背包（背包满则掉落在拆解台上方）；不设全局余额，散落在背包/箱子里的点数无法统计。
  • 点击背包物品放入投料口 → 点「拆解」按钮执行回收 → 快捷栏中武库点数堆叠数量增加；点击投料口物品可取回。悬停任意物品显示原版 tooltip。
  • 回收数值为当前实现：3 / 5 / 7 / 8 / 8（g1→g5，clamp 于钥匙成本 9 之下）。
  • 演示物品来自高级箱默认池（石/铁/金/钻/下界合金），品级 1→5。
